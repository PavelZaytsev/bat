# BAT brand assets

`bat-mascot.png` is original project artwork generated for BAT with OpenAI image generation on
2026-08-07. It is documentation-only and is not a runtime dependency.

The art direction called for an original, muscular anthropomorphic bat exterminator in a
1990s-action-cartoon and airbrushed-PC-box-art aesthetic: cigar, full tattoo sleeve, visibly patched
opposite arm, smoking belt-fed machine gun, and defeated cartoon software bugs. The generation
prompt explicitly excluded text, logos, trademarks, watermarks, and copies of existing franchise
characters, poses, or compositions.

Keep future replacements original and record their source and art direction here.
